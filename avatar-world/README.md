# Avatar World 捏脸换装馆

一个纯静态的捏脸换装小站：用 Canvas 实时画出一个可爱风的半身虚拟形象，背景、肤色、发型、发色、眼睛、眉毛、嘴巴、腮红、服装、配饰十个维度随意搭配，保存到本地画廊、导出 PNG、或生成分享链接发给朋友。

## 怎么玩

1. 打开页面就能看到默认形象，点「随机捏一个」碰运气，或点「重置」回到默认。
2. 在「定制」面板里逐组点选：背景、肤色、发型、发色、眼睛、眉毛、嘴巴、腮红、服装、配饰，点一下立即重绘。
3. 也可以直接用「预设」里的三个现成形象（草莓甜妹 / 街头酷哥 / 墨染古风）起步再微调。
4. 满意后点「保存这个形象」，它就会出现在下方画廊；画廊里点缩略图可以载回继续编辑，右上角 × 删除，最多保存 12 个（满了自动删最旧的）。
5. 点「导出 PNG」把当前形象下载成图片；点「复制分享链接」把带配置的链接复制给朋友，对方打开就是你捏的形象。

## 本地打开

- 最简单：双击 `index.html` 用浏览器打开（保存/导出/分享在 `file://` 下也能用）。
- 或起个本地静态服务：`python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 部署

纯静态站（HTML/CSS/原生 JS，无构建、无依赖），把整个目录直接托管到任意静态托管（Altare、GitHub Pages、对象存储等）即可，无需任何服务端。

## 文件清单

| 文件 | 说明 |
|---|---|
| `index.html` | 页面骨架（标题栏 / 预览画布 / 按钮行 / 定制面板 / 画廊） |
| `styles.css` | 手机优先样式，桌面端预览与面板左右并排 |
| `js/state.js` | 默认配置、随机配置、3 个预设、`render()` 入口 |
| `js/avatar.js` | 纯 Canvas 绘制核心 + 选项清单 `OPTIONS` |
| `js/ui.js` | 定制面板 UI（分组按钮、选中态、预设、随机/重置） |
| `js/gallery.js` | 保存画廊（localStorage）、导出 PNG、分享链接 |
| `test-avatar.js` | Node 自测（mock canvas，`node test-avatar.js` 运行） |
